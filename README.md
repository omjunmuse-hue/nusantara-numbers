Nusantara in Numbers: a national statistics site for Indonesia — headline indicators with source and year on every figure, population and growth charts, a people page with the age shape and poverty series, an economy page with trade and work, a sortable searchable table of all 38 provinces with computed densities, and a sources register. Vanilla JS modules, no framework, nothing fetched.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts — then open out/app/index.html in a browser (or serve app/ statically)
```
